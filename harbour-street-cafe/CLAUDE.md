# Working in this folder (Harbour Street Café)

- Original data files are read-only: never edit, rename or overwrite them. Put cleaned or combined data in a new file.
- Work out what a file covers from its contents (dates, columns), not its filename.
- If data has problems (repeated rows, blank or total lines, mismatched columns, totals that don't add up), stop and ask before changing anything.
- Every figure must reconcile with the source files. Show that check in the result.
- Before delivering, ask whether it should be a file to open locally or a private shareable page.
- Never present a snapshot as live data. Say where the figures came from and when.
- Amounts are Singapore dollars. Explain things in plain language.
